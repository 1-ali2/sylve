后台保活与通知

后台保活

开启后会在后台循环播放一段静音音频，让浏览器尽量别把这个网页冻住，这样切到别的 App 时 TA 的消息也能按时来。只要不从后台划掉、也不关闭网页就有效。

新消息通知

说明：浏览器只有在 https 网址（比如放到 GitHub Pages 这类网页托管）或「添加到主屏幕」后才稳定支持系统通知；直接打开本地文件时，很多手机浏览器不允许弹通知，这时我会改成标签页标题闪烁 + 震动提醒。iPhone 的 Safari 会更激进地暂停后台网页，没法保证一直在线。

回复规则

抽卡来源

TA 的回复不经过任何 AI，只从字卡库里随机抽。选不同分组，语气就不一样。

TA 回我消息的间隔

你发出一条后，TA 隔「最短—最长」之间随机一个时间再回你这一条。只管「他回你」的速度，和下面的「TA 主动发消息的间隔」是两件独立的事，互不影响。

拼字卡

开启拼字卡回复

开启后，TA 回复时会把几张字卡连成一句话一起发；不开启就一次只发一张（还是可能连回几条）。拼几张在「最少—最多」之间随机。

TA 用 emoji / 颜文字

回复里随机带一点

开启后，TA 回复会在句尾随机带一个 emoji 或颜文字（不是每条都带）。输入框旁边的 (・ω・) 面板里可以自己加、删颜文字。

输入提示

消息流里显示「正在输入」气泡

等 TA 回复、TA 正在打字时，聊天流末尾 TA 头像下会出现「三个点」气泡。形式固定这一种，不会来回切换。

TA 的状态库

TXT 一行一条状态；竖线 | 后面可以写分类（状态库没有分组，分类名会被忽略）；空行和 # 开头的行忽略。UTF-8 和 GBK 记事本都能自动识别。

状态显示在聊天顶栏名字下面。「随机」时每次打开页面换一条，「固定」时一直显示你选的那条。

对方主动行为

TA 主动发消息的间隔（分钟）

你不说话时，TA 自己隔「最短—最长」之间随机一个时间开口。跟「TA 回我消息的间隔」互不干扰：调这个不会让他回你变慢，调那个也不会让他更爱主动开口。

主动发表情包

开启后，TA 才会主动单独发表情包；间隔没到绝不发。TA 平时回复你的时候不会再自动带表情包图片。

主动发红包

TA 只能用自己零钱里的余额发红包（余额来自你发给他、和他领你的红包），余额不够就不发。发出的红包你点一下就能收下。

多久送一次礼物（分钟，0 为不送）

TA 主动送礼至少隔这么久才可能再来一次（默认 45 分钟）；填 0 表示 TA 不主动送礼。同一时间只留一件待收下的礼物，一次只送一件；聊天里提到商品名想让 TA 买给你，也走同一套限制。冷却没到时不会有任何送礼迹象。

主动打电话

开关打开后，TA 会自己来找你——发消息、发表情包、打电话、发红包，时机和内容都随机。页面开着才触发；切到后台再回来，错过的会补上。

信箱

「每天写几封」填 0 就不主动写信。TA 的信从你的字卡库里抽字（抽哪些、抽几张在「字卡抽取」里设），也可以带 emoji 和颜文字；信的开头自动写「致 你的昵称」，结尾自动落款（写信人 + 日期时间）。你写给 TA 的信，收信人自动用你设置的梦角名字。

字卡抽取

抽哪些字卡

一个都不勾＝全部字卡都参与抽取。分组本身在「字卡库 → 分组管理」里管，这里只做筛选，不会动你的分组。

怎么抽

「按顺序轮换」是照着字卡库的顺序一张一张来；「不重复优先」会尽量避开刚抽过的那几张。

分别抽多少张

三处各抽各的，互不串：日常回消息、回信、主动发消息。信里只显示是从哪儿抽的（只读），要改来这里改。

朋友圈设置

点赞与评论

你发朋友圈、或评论 TA 的动态之后，TA 会在「最短—最长秒数」之间随机一个时间来点赞、回复。

自动发圈

TA 自动发朋友圈

TA 想发就发，节奏由这里的最短—最长间隔决定（内容从字卡库和表情包库里随机抽）。这里只管频率，没有任何「催他发一条」的按钮——要不要发、发几条，永远由 TA 自己决定。

头像样式

圆形、胶囊形、方形都能选；方形的圆角和所有头像的大小都可以调。

字体

内置霞鹜文楷、思源黑体、思源宋体，走 CDN 在线加载；断网或加载失败会自动用回系统字体。也可以贴自己的字体 CSS 链接。

通话

通话是界面模拟，不会真的联网拨号，也不产生费用。通话中可以点右上角「缩小」，缩成悬浮小窗回聊天继续聊，随时点开恢复。

聊天会话

每个会话的消息、占卜记录、信件各自独立；字卡库、商城、设置、表情包是全局共用的。新会话是干净的，可以重新开始聊。

数据与备份

数据存在这台设备的浏览器存储里，能放几万张字卡和不少表情包。换设备、清理浏览器数据会丢，建议定期「导出备份」。
